# 📱 Appium Automation Project

Mobile UI automation testing project using Appium and Java.

## 🛠️ Tech Stack

- **Language:** Java
- **Framework:** Appium
- **Build Tool:** Maven

## 🚀 Run Tests

```bash
mvn test
```

## 📁 Project Structure

```
appium_project/
├── src/
│   └── test/        # Test classes
└── pom.xml          # Maven dependencies
```

## 📋 What's Tested

Mobile application UI flows including user interactions, navigation, and functional validations using the Page Object Model pattern.
